# az vi

```bash
# Add a camera to a Video Indexer Extension.
az vi camera add

# List all cameras associated with a Video Indexer Extension.
az vi camera list

# Show Video Indexer Extension details.
az vi extension show

# Perform diagnostic checks on a Video Indexer Extension.
az vi extension troubleshoot
```
